# uc-auction-backend

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `MONGODB_URI` | да | подключение к MongoDB |
| `ADMIN_KEY` | да | ключ доступа к админским REST-эндпоинтам; также используется ботами для внутренних вызовов `/use-promo` и `/use-referral` |
| `USER_BOT_TOKEN` | да | токен пользовательского бота; также используется для проверки подписи Telegram WebApp `initData` |
| `ADMIN_BOT_TOKEN` / `ADMIN_CHAT_ID` | нет | админ-бот с уведомлениями и управлением |
| `CHANNEL_ID` | нет | канал для публичных объявлений об аукционах/голосованиях |
| `BOT_USERNAME` | да (по факту) | username бота для ссылок; сейчас установлен как `ucbid_uz_bot`, дефолт в коде на случай если переменная не задана — тот же |
| `PAYMENT_CARD` / `PAYMENT_NAME` | нет | реквизиты, которые показывает бот при покупке коинов |
| `PORT` | нет | порт HTTP/WS-сервера (по умолчанию 3000) |
