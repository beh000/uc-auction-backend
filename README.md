# uc-auction-backend

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `MONGODB_URI` | да | подключение к MongoDB |
| `ADMIN_KEY` | да | ключ доступа к админским REST-эндпоинтам |
| `INTERNAL_KEY` | да | секрет для служебных вызовов между процессом сервера и ботами (`/use-promo`, `/use-referral`) — без него эти два эндпоинта отклоняют все запросы |
| `USER_BOT_TOKEN` | да | токен пользовательского бота; также используется для проверки подписи Telegram WebApp `initData` |
| `ADMIN_BOT_TOKEN` / `ADMIN_CHAT_ID` | нет | админ-бот с уведомлениями и управлением |
| `CHANNEL_ID` | нет | канал для публичных объявлений об аукционах/голосованиях |
| `BOT_USERNAME` | нет | username бота для ссылок (по умолчанию `UCBidbot`) |
| `PAYMENT_CARD` / `PAYMENT_NAME` | нет | реквизиты, которые показывает бот при покупке коинов |
| `PORT` | нет | порт HTTP/WS-сервера (по умолчанию 3000) |

`INTERNAL_KEY` — любая случайная строка, известная только серверу (одинаковое значение переменной окружения на бэкенде — она используется только внутри процесса, боты обращаются к серверу через `127.0.0.1`).
